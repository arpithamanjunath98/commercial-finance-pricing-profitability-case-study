# Project Description

## Commercial Finance — Pricing, Margin & Customer Profitability

Built an end-to-end Commercial Finance case study for a simulated UK FMCG company using 2,000 transaction-level sales records across 90 customers and 48 SKUs.

Created a SQLite/SQL analysis workflow and Excel commercial-finance model to evaluate customer, product, channel and promotional profitability after discounts, COGS, freight and promotional spend. Developed discount-leakage diagnostics, customer and SKU profitability matrices, customer concentration analysis and a Jan–Sep Price–Volume–Mix bridge.

Extended the analysis with Conservative/Base/Stretch repricing scenarios that balance discount recovery against customer-volume retention, plus a customer action register, automated Commercial Finance commentary and an executive management pack.

**Tools:** Excel, SQL, SQLite  
**Power BI:** star schema, DAX measure library and report specification prepared; no PBIX file claimed  
**Project type:** Independent synthetic case study
